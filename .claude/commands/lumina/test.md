Giao cho agent `qa-tester` kiểm thử: $ARGUMENTS

Agent phân tích yêu cầu, thiết kế test case (phân vùng tương đương/giá trị biên/bảng quyết định/chuyển trạng thái), truy vết bằng ma trận bao phủ, thực thi trong phạm vi được giao, báo cáo bug kèm đánh giá rủi ro còn lại. Không tự triển khai tính năng mới, không tự sửa code ứng dụng để làm test đạt.
