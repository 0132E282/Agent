# Mẫu Báo Cáo Thay Đổi

Dùng ngay sau khi Edit/Write hoàn tất một task code. Copy khối dưới đây và điền vào.

```markdown
## 📝 Báo cáo thay đổi

### Files đã thay đổi
- `path/to/file.ext` — [mô tả ngắn gọn]

### Chi tiết thay đổi

#### 1. [Tên file]
**Dòng [X-Y]**: [mô tả thay đổi]

🔴 Code cũ:
```[lang]
// code cũ
```

🟢 Code mới:
```[lang]
// code mới
```

**Lý do**: [tại sao thay đổi — vấn đề nghiệp vụ/kỹ thuật nào được giải quyết]

### Tóm tắt
- ➕ Thêm mới: [số dòng/function]
- ✏️ Sửa đổi: [số dòng/function]
- ➖ Xóa bỏ: [số dòng/function] (nếu có)
```
